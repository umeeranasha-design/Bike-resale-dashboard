# Bike-resale-dashboard
# 🚲 Bike Resale Analytics Dashboard

## 1. Project Title / Headline

### 🚲 Bike Resale Analytics: Indian Used Bike Market Insights Dashboard

An interactive Power BI dashboard designed to analyze the Indian bike resale market, focusing on inventory distribution, brand popularity, fuel types, insurance status, and resale price trends.

---

## 2. Short Description / Purpose

The **Bike Resale Analytics Dashboard** is an interactive Power BI report developed to provide insights into **10,000 bike resale listings across India**.

The dashboard helps users explore bike inventory, compare brands, understand fuel-type preferences, analyze insurance status, and track average resale price trends across different manufacturing years.

This dashboard is useful for understanding market patterns and supporting data-driven decisions related to bike buying, selling, pricing, and inventory analysis.

---

## 3. Tech Stack

The dashboard was built using the following technologies:

* 📊 **Power BI Desktop** – Main data visualization platform used to create the interactive dashboard.
* 📂 **Power Query** – Used for data cleaning, transformation, and preparation.
* 🧠 **DAX (Data Analysis Expressions)** – Used to create calculated measures, KPIs, and analytical calculations.
* 📐 **Data Modeling** – Used to structure the data and enable filtering and aggregation across dashboard visuals.
* 📁 **File Format** – `.pbix` for the Power BI dashboard and `.png` for dashboard previews.

---

## 4. Data Source

**Source:** Kaggle

The dataset contains **10,000 bike resale listings** from India.

The dataset includes information such as:

* Brand
* Resale Price
* Manufacturing Year
* Mileage
* Fuel Type
* Insurance Status
* State
* Original Price / Depreciation information

The data was cleaned and transformed before being used for analysis and dashboard development.

---

## 5. Features / Highlights

### 🔹 Business Problem

The Indian used-bike market contains a large number of listings with different brands, prices, manufacturing years, mileage levels, fuel types, insurance statuses, and locations.

Analyzing this information using raw data can make it difficult to identify important market patterns.

Key questions include:

* Which states have the highest number of bike listings?
* Which brands have the largest inventory?
* Which fuel type is most common?
* What is the insurance status of listed bikes?
* How does average resale price change across manufacturing years?
* What are the overall resale market KPIs?

---

### 🎯 Goal of the Dashboard

The goal of this dashboard is to provide an interactive analytical view of the Indian bike resale market.

The dashboard enables users to:

* Analyze bike inventory across Indian states.
* Compare listing volumes across different brands.
* Understand fuel-type distribution.
* Analyze insurance status across listings.
* Track resale price trends by manufacturing year.
* Monitor important business KPIs.
* Support data-driven market and pricing analysis.

---

## 📊 Key Metrics

The dashboard includes five key performance indicators:

* **Total Listings** — Overall count of bikes listed for resale.
* **Avg Resale Price** — Average resale price across all listings.
* **Avg Depreciation** — Average depreciation percentage from the original price.
* **Insurance Active %** — Share of listings with active insurance.
* **Avg Mileage** — Average mileage (kmpl) across listed bikes.

## 📈 Walkthrough of Key Visuals

### 📍 State-wise Inventory

A **map view** showing the distribution and density of bike listings across Indian states.

This visual helps identify regions with higher and lower concentrations of resale bike inventory.

---

### 🏍️ Brand Distribution

A **horizontal bar chart** displaying the total number of listings by brand.

The dashboard compares:

* Kawasaki
* Yamaha
* KTM
* Royal Enfield
* Hero
* TVS
* Honda
* Bajaj

This helps identify which brands have the highest representation in the resale market.

---

### ⛽ Total Listings by Fuel Type

A **bar chart** comparing the number of listings across:

* Hybrid
* Petrol
* Electric

This visual provides an overview of the distribution of different fuel types within the resale market.

---

### 🛡️ Total Listings by Insurance Status

A **donut chart** showing the distribution of bikes based on insurance status:

* Active
* Expired
* Not Available

This helps users understand the insurance coverage profile of bikes listed for resale.

---

### 📉 Price Trend by Year of Manufacture

A **line chart** tracking the average resale price across different manufacturing years.

This visual helps identify how bike resale prices change based on the year of manufacture and provides insight into depreciation and pricing trends.
